# PRD: MENSA Pair Game

## 1. 개요

### 프로젝트 목적
로그인이나 설치 없이 브라우저에서 바로 즐길 수 있는 IQ/패턴 인지 테마의 카드 짝 맞추기(memory matching) 게임을 제공하여, 사용자가 짧은 시간 동안 기억력과 패턴 인지력을 재미있게 훈련하도록 한다.

### 타겟 사용자
- 두뇌 트레이닝/기억력 게임을 가볍게 즐기고 싶은 청소년~성인 캐주얼 사용자
- MENSA류 인지능력 테스트나 IQ 트레이닝에 관심 있는 사용자
- 별도 회원가입 없이 웹 브라우저에서 즉시 플레이하고 싶은 1인 사용자 (PC/모바일 웹 모두)
- **(v2) 유치원생~초등학교 저학년 어린이 사용자** — 밝고 친근한 캐릭터 테마를 좋아하며, 부모/보호자의 도움 없이도 큰 글씨·직관적인 그림만으로 규칙을 이해하고 플레이할 수 있어야 함
- **(v2) 같은 화면에서 형제자매·친구와 번갈아 플레이하고 싶은 2인 사용자**

### 핵심 가치 제안
설치·가입 없이 웹 브라우저만 열면 즉시 시작할 수 있는, 난이도 선택이 가능한 패턴 카드 짝 맞추기 게임으로 기억력 훈련과 자기 기록 갱신의 재미를 제공한다. **(v2)** 여기에 더해, 어린이 눈높이에 맞는 테마를 골라 화면을 꾸미는 재미와, 친구·형제자매와 한 화면에서 번갈아 대결하는 2인 플레이 재미를 추가로 제공한다.

## 2. 기능 요구사항

### 기능 1: 카드 짝 맞추기 플레이 (핵심 게임플레이)

**사용자 스토리**
> 두뇌 트레이닝을 즐기려는 사용자로서, 카드를 뒤집어 같은 패턴의 짝을 찾고 싶다, 기억력과 패턴 인지력을 재미있게 훈련하기 위해

**수용 기준**
- [ ] 뒤집혀 있지 않은 카드를 클릭하면 카드가 앞면(숫자/도형/패턴)으로 뒤집혀 보인다
- [ ] 동시에 최대 2장까지만 뒤집을 수 있으며, 두 카드의 짝이 맞지 않으면 1초 이내에 자동으로 다시 뒷면으로 뒤집힌다
- [ ] 이미 짝이 맞아 확정된 카드나 현재 뒤집힌 2장 외의 세 번째 카드를 클릭해도 추가 반응이 일어나지 않는다
- [ ] 모든 카드의 짝을 맞추면 "게임 완료" 메시지와 함께 총 시도(뒤집기) 횟수와 소요 시간이 화면에 표시된다

### 기능 2: 난이도(카드 수) 선택

**사용자 스토리**
> 다양한 숙련도의 사용자로서, 카드 개수(난이도)를 선택하고 싶다, 자신의 수준에 맞는 도전을 하기 위해

**수용 기준**
- [ ] 게임 시작 화면에서 쉬움(3x2=6장), 보통(4x4=16장), 어려움(6x4=24장) 3가지 난이도 중 하나를 선택할 수 있다
- [ ] 난이도를 선택해 게임을 시작하면 선택한 장수만큼 정확히 짝이 맞는 카드 쌍이 매번 무작위로 배치된 상태로 새 게임이 시작된다
- [ ] 난이도를 선택하지 않고 게임 시작을 시도하면 기본값인 "보통" 난이도로 자동 진행된다
- [ ] 게임 진행 중 난이도를 변경하면 현재 진행 상황은 초기화되고 선택한 난이도로 새 게임이 시작된다

### 기능 3: 최고 기록 저장 및 표시

**사용자 스토리**
> 반복적으로 게임을 플레이하는 사용자로서, 자신의 최고 기록(최소 시도 횟수, 최단 시간)을 저장하고 확인하고 싶다, 이전 결과와 비교하며 성취감을 느끼고 재도전하기 위해

**수용 기준**
- [ ] 게임을 완료하면 이번 기록(시도 횟수, 소요 시간)이 같은 난이도의 저장된 최고 기록과 자동으로 비교된다
- [ ] 이번 기록이 기존 최고 기록보다 우수한 경우(더 적은 시도 횟수 또는 더 짧은 시간) "신기록" 표시가 나타나고 그 기록으로 갱신·저장된다
- [ ] 브라우저를 새로고침하거나 다시 방문해도 이전에 저장된 난이도별 최고 기록이 그대로 유지되어 표시된다
- [ ] 해당 난이도로 처음 플레이하여 저장된 기록이 없는 경우 "최고 기록 없음"으로 표시되고, 이번 플레이 결과가 해당 난이도의 최초 기록으로 저장된다

### 기능 4 (v2): 어린이 친화적 디자인 테마 선택

**사용자 스토리**
> 유치원생~초등학교 저학년 어린이 사용자로서, 내가 좋아하는 캐릭터 테마(동물/우주/바다 등)를 골라 게임 화면을 꾸미고 싶다, 더 친근하고 재미있게 게임을 즐기기 위해

**수용 기준**
- [ ] 화면에서 3가지 테마( 동물 친구 / 우주 탐험대 / 바다 친구 ) 중 하나를 클릭 한 번으로 선택할 수 있다
- [ ] 테마를 선택하면 카드 뒷면 무늬, 카드 앞면 그림(이모지), 배경색, 강조색이 테마에 맞는 밝고 화사한 색상 조합으로 즉시 바뀐다
- [ ] 테마를 선택하지 않고 처음 접속하면 기본 테마( 동물 친구 )가 자동으로 적용된다
- [ ] 테마를 변경하면 난이도를 바꿀 때와 동일하게 현재 진행 상황이 초기화되고 선택한 테마·현재 난이도로 새 게임이 시작된다
- [ ] 새로고침하거나 다시 방문해도 마지막으로 선택한 테마가 그대로 유지된다 (localStorage)
- [ ] 모든 테마에서 카드 식별은 색상이 아닌 그림(이모지) 모양으로 가능해야 한다(색약 아동 고려, 기존 접근성 요구사항 유지)

### 기능 5 (v2): 2인 플레이 모드

**사용자 스토리**
> 형제자매나 친구와 함께 게임하고 싶은 사용자로서, 한 화면에서 번갈아 카드를 뒤집으며 누가 더 많은 짝을 맞추는지 겨루고 싶다

**수용 기준**
- [ ] 게임 시작 전 "1인 플레이"와 "2인 플레이" 중 하나를 선택할 수 있으며, 선택하지 않으면 기본값인 "1인 플레이"로 진행된다
- [ ] 2인 플레이 중에는 지금이 "Player 1"과 "Player 2" 중 누구의 차례인지, 그리고 각자의 현재 점수(맞춘 짝 수)가 화면에 항상 표시된다
- [ ] 현재 차례인 플레이어가 카드 짝을 맞추면 그 플레이어의 점수가 1 올라가고, 같은 플레이어가 이어서 한 번 더 차례를 진행한다
- [ ] 현재 차례인 플레이어가 짝을 틀리면(불일치) 카드가 자동으로 다시 뒤집힌 뒤 상대 플레이어에게 차례가 넘어간다
- [ ] 모든 카드의 짝을 다 맞추면 "게임 완료" 대신 최종 점수와 승자("Player 1 승리!" / "Player 2 승리!" / "무승부!")가 표시된다
- [ ] 2인 플레이 결과는 최고 기록(시도 횟수·시간)에 저장되지 않으며, 1인 플레이로 다시 전환하면 기존 최고 기록 저장·표시 기능은 이전과 동일하게 정상 동작한다

## 3. 비기능 요구사항

### 성능
- 최초 페이지 로드(정적 파일) 완료까지 일반 브로드밴드 기준 2초 이내
- 카드 클릭 후 뒤집기 반응까지 200ms 이내
- 짝이 맞지 않은 카드가 다시 뒷면으로 돌아가는 시간은 1초로 고정

### 보안
- 회원가입/로그인 절차 없음, 개인정보(이름, 이메일 등) 수집 없음
- 서버로 전송되는 사용자 데이터 없음(모든 게임 데이터는 사용자 브라우저 내부에만 존재)

### 접근성
- 마우스뿐 아니라 키보드(Tab 이동 + Enter/Space 선택)로도 카드 선택 및 뒤집기가 가능해야 한다
- 카드 구분은 색상에만 의존하지 않고 숫자 또는 도형 모양으로도 식별 가능해야 한다(색약/색맹 사용자 고려)
- 모바일 및 데스크톱 브라우저 화면 크기에 맞춰 카드 그리드가 자연스럽게 배치되어야 한다

### 사용성 (v2, 어린이 친화적 UI)
- 테마 선택 버튼, 난이도 선택 버튼, 카드 등 클릭 대상은 어린이가 실수 없이 누를 수 있도록 충분히 크게 표시한다
- 화면에 노출되는 문구는 한글 기준 초등학교 저학년도 읽을 수 있는 쉬운 표현을 사용한다
- 글자 대신 그림(이모지) 위주로 정보를 전달해 아직 읽기에 익숙하지 않은 유아도 직관적으로 이해할 수 있게 한다

## 4. 제약사항

### 기술적 제약
- 정적 파일(HTML/CSS/JS) 기반의 싱글 페이지 웹 게임으로 구현하며, 별도의 백엔드 서버나 데이터베이스를 사용하지 않는다
- 사용자 계정/로그인 시스템을 두지 않는다
- 모든 게임 데이터(최고 기록 등)는 브라우저 로컬 저장소에만 보관하며, 외부 서버와 동기화하지 않는다

### 비즈니스 제약
- 내부 데모/포트폴리오 목적의 MVP로, 별도의 출시 일정·예산 제약은 없다
- 외부 유료 API나 서드파티 서비스 연동은 포함하지 않는다

---

## 5. 성공 지표
- 게임 페이지 접속 후 첫 카드 클릭까지 평균 5초 이내에 이루어진다 (직관적으로 바로 플레이 가능한지 확인)
- 게임을 시작한 세션 중 70% 이상이 한 라운드(짝 전부 맞추기)를 끝까지 완료한다
- 최고 기록의 저장 및 불러오기(localStorage 읽기/쓰기) 성공률 100%, 관련 오류 0건
- 쉬움/보통/어려움 3가지 난이도 모두 QA를 통해 최소 1회 이상 정상적으로 시작부터 완료까지 플레이 가능함을 확인한다
- **(v2)** 3가지 테마( 동물 친구 / 우주 탐험대 / 바다 친구 ) 모두 QA를 통해 정상적으로 전환·플레이됨을 확인한다
- **(v2)** 2인 플레이 모드로 한 라운드를 끝까지 진행했을 때 점수 집계와 승자 판정이 매번 정확함을 QA로 확인한다
